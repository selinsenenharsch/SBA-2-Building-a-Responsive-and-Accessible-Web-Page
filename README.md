# Accessible Design Co.

## Project Description
Accessible Design Co. is a responsive and accessible website created as part of the Per Scholas SBA 2 assignment. The website introduces the company's services and provides a way for visitors to get in touch.

## Features
- Responsive navigation bar
- Hero section with an illustration
- About and Services sections
- Contact form with labeled fields
- Accessible image descriptions and keyboard focus styles
- Responsive layout for different screen sizes

## Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

## Testing
I tested the website using different browsers and screen sizes to check its appearance and responsiveness. I also reviewed the form labels and other accessibility features.

## Purpose
The goal of this project was to practice building a responsive website while applying HTML, CSS, and accessibility principles.

*Reflection Questions*

 1. What accessibility challenges did you face, and how did you address them?

One of the challenges I faced was making sure that the website's images displayed correctly, especially adjusting their height, width, and proportions using CSS. Interestingly, I spent more time dealing with image sizes and pixels than searching for HTML labels! I also paid close attention to accessibility labels and made sure that the form fields were clearly identified.

2. How did you ensure that your design was responsive and accessible to all users?

I tested my website on different browsers and devices to make sure the layout worked properly across different screen sizes. I also tried to be careful with accessibility by checking the labels, image descriptions, and form fields to make the website easier to navigate and understand.

3. What tools or resources did you find most helpful during this project?

Google was one of my main tools when I needed answers or solutions. Whenever I searched for something, I often found myself returning to websites and resources that had already been shared during class. These resources were helpful because they provided clear explanations and practical examples that I could apply to my project.
